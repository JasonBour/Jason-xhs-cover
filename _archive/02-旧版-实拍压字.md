# 风格卡：实拍压字（已退役）

> ⚠️ **本卡已退役，不再出图。** 它没有对应的真实参考图，是早期凭印象搭的卡。
> 编号 **02** 现在指向「[上下压边](../style-library/02-上下压边.md)」——顶部一行大标签 + 底部两行大字，上下一夹、中间露人。
> 保留此文件仅为可追溯。

> **核心画像**：真人/场景实拍当底图 + 超大粗体字直接压上去（**无蒙层**）+ 单图双色系统 + 文字只占一个专属区 + 靠白描边/暗部/背景虚化保可读。
>
> 和「半透明照片叠字」（有蒙层、更克制商务）是两条路。这张走的是**裸压大字**，人物和字一样醒目——是真人 IP 封面主打路数。
>
> **核心用法**：这套风格卡不靠用户"选变体"，而是**看图自动分流**——底图进来先判底色明暗/冷暖，自动定字色方案 + 布局。用户负责给图和文案，派发我来。

```yaml
name: 实拍压字
status: archived
category: 实拍+大字压图（真人 IP 主打）

fits:
  - 对话/访谈/观点输出（真人出镜）
  - 干货教程/工具清单（场景+设备）
  - 女性成长/态度人设内容
  - 一切"露脸 + 强观点标题"的封面

# —— 不可变的共同内核（任何底图都必须满足）——
core:
  base_image: 真实拍摄底图（非纯色/非插画）——真人半身或带氛围的场景/产品照
  overlay: 无蒙层 —— 禁止叠半透明色块，靠描边/暗部/虚化保可读
  typeface: 超粗黑体 heavy（中文大字）
  color_system: 单图双色 —— 主字色 + 白辅助，双色上限
  text_zone: 文字只堆在一个专属区（顶部或对角），其余画面让给主体
  readability: 白描边(3px+) 或 轻投影 或 依赖底图暗部，按底色三选一
  no_sticker: 不加小型分类标签
  face_safe: 真人露脸时，文字避开面部

# —— 派发规则（THE核心）：看底图 → 自动定方案 ——
dispatch:
  先看底色明暗和冷暖，落到下面一条规则：

  # 【A 暖调底 / 黄棕橙暖色占主】
  #    背景偏暖（木纹墙/暖光灯/夕阳/肤色大占比暖色）
  #    → 字色取「与底色同族的深暖黄 或 金黄 + 白辅助」
  #    示例：暖木纹墙真人底 → 金黄 #E8B92E 主字 + 白短句，顶部堆叠
  #    本批 Codex 图即此族。
  A_暖调底:
    primary: "#E8B92E"   # 金黄，与暖底同族，画面和谐不跳脱
    secondary: "#FFFFFF"
    shadow: 轻投影(深暖投影增强可读)
    layout: 顶部双段堆叠(上白短句小字 + 下金黄主标题大字)
    逻辑: 暖底+同族字色 = 高级不刺眼；暖色字会融进画面，白字负责跳出来

  # 【B 冷调亮底 / 浅色净底】
  #    背景偏冷或偏浅净（白墙/冷光/天空/浅色）
  #    → 字色取「冷色强调 + 白辅助」，深色描边兜底
  #    冷字暖底、强反差
  B_冷调亮底:
    primary: "#A8BFF2"   # 淡蓝紫
    secondary: "#FFFFFF"
    shadow: 白描边3px+轻投影
    layout: 对角动线(右上大语块+左下补全+可选底部英文小字)
    逻辑: 浅净冷底直接裸压，冷色字+白描边照样成立，可放对角大字

  # 【C 深暗底 / 夜景暗调】
  #    背景明显偏暗（夜景/暗调氛围/深色背景）
  #    → 字色取「亮色(金黄/白) + 白辅助」，暗部天然当蒙层
  #    本批 Codex 即此族，实际与 A 同方案(金黄+白)但更亮。
  C_深暗底:
    primary: "#E8B92E"
    secondary: "#FFFFFF"
    shadow: 轻投影(或直接依赖暗部，可不加影)
    layout: 顶部双段堆叠
    逻辑: 暗底+亮字天然可读，金黄/白最稳

  # 兜底：底色判断不了(噪点多/花) → 默认走 A 暖调+金黄，简单安全。

# —— 布局双雄（对应底色倾向的两套摆法，非硬编码变体）——
layouts:
  top_stack:  # 顶部双段堆叠：干货/教程/数字标题首选
    structure: 顶部居中双行(上白短句小 + 下强调色主标题大，主标题可折行)
    fits: 有数字/具体利益点/教程感的标题(如「5个隐藏功能」「3个副业」)
    限制: 文字压顶部约1/4，主体完整露出
  diagonal:  # 对角动线：观点/人设/悬念标题首选
    structure: 右上大字块+左下补全字块，可加底部英文小字，Z型动线
    fits: 四字短句拆两语块制造悬念(如「从尬聊→到深聊」)、态度观点题
    限制: 语块避开人物面部

# —— 代表样本（供图生图参考）——
samples:
  - style-library/实拍压字/sample-01_真人变体-从尬聊到深聊.png  # 冷调亮底对角(其实底色暖)…
  - style-library/实拍压字/sample-02_场景变体-codex隐藏功能.png  # 深暗底顶部金黄

one_liner: 看图定方案的真人/场景裸压大字——暖底金黄、冷底冷色、暗底亮字，双色系统直接压图
```

## Compose 流程（覆盖 SKILL.md 的 Stage 3 判断逻辑）

1. 看底图 → 按 `dispatch` 规则定主色 + 布局，**不再问用户选哪个变体**（用户只给图和文案）。
2. 主标题逐字放 prompt；数字/利益点标题走 top_stack，观点/悬念短句走 diagonal。
3. 出图后**逐字核对画面文字**（AI 中文易错字），有错立即修。
4. 交付时说明用了哪条 dispatch 规则、为什么这么配色。

## 已知边界 / 待细化

- 色值 `#A8BFF2` / `#E8B92E` 是目测估算，图生图参考样本图会比我给 hex 更准。
- 真人版脸部避让是隐性约束——prompt 里强调"文字不遮脸"。
- dispatch 规则目前 3 条(A暖B冷C暗)，真人/场景样本继续喂会补齐更多底色调（冷白光、深绿、单色块背景等）。
- 图片底色误判时，用户口头纠偏一次即可校准（改 dispatch 对应规则）。
