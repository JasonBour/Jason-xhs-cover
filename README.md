# cover-style-lab · 封面风格库

把「我看到一张好封面，但说不清它好在哪」变成「一组能抄下来的参数 + 一条命令出图」。

风格不是玄学，是参数。能抄下来的才是风格，抄不下来的只是感觉。

---

## 两张风格卡

| 编号 | 样式 | 识别特征 | 适合 |
|---|---|---|---|
| **01** | 描边压脸 | 纯黑描边 + 黄色钩子行 + 白色结论行，多行堆叠、**整块钉在画面正中** | 一句话标题、真人口播、赚钱认知、工具教学 |
| **02** | 实拍压字 | 无描边、双色裸压、文字**避开**脸堆顶部 | 短语/数字点标题、观点对话、干货教程 |

两张卡内核相反，参数不能混用。编号只增不改。

---

## 快速开始

```bash
pip install pillow opencv-python-headless jieba

# 样式01：手动断行（推荐，断行位置本身就是设计）
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --split "如何用 AI|找到属于自己的|隐藏天赋！"

# 样式01：整句标题，自动断行
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --title "如何用 AI 找到属于自己的隐藏天赋！"
```

出图器会自动完成：裁 3:4 → 分词断行（jieba + 中文禁则，不拆词）→ 自适应字号 → 按字形墨迹居中 → 黑描边 → 投影 → 输出。

### 样式01 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--title` | — | 整句标题，自动断行 |
| `--split` | — | 手动分行，`\|` 分隔（优先级更高） |
| `--accent` | `#FFD400` | 首行钩子色 |
| `--font` | `noto` | `noto` 思源黑体 Heavy / `yahei` 微软雅黑 Bold / `heiti` 黑体 |
| `--offset-y` | `0` | 在正中基础上的微调像素（正=下移），建议 ±40 以内 |
| `--size-ratio` | `0.116` | 正文字号 / 画布宽 |
| `--stroke-ratio` | `0.080` | 描边 / 字号 |
| `--tracking` | `-5` | 字距（按 1080 基准自动缩放） |

## 设计常量（样式01）

全部相对画布宽度 W，换尺寸也成立：

```
可用宽度      0.83 W
描边粗细      0.080 × 本行字号
行距          1.36 × 正文字号        # 行中心 → 行中心
行字号阶梯    0.91 / 1.00 / 1.065    # 首行收、末行放大落点
字块中心      0.5 W, 0.5 H           # 硬约束：整块墨迹钉在画布正中
投影          黑 58/255，偏移 0.0074 W，模糊 0.0056 W
```

正文字号固定 `0.116 W`，长文案靠缩小兜住、短文案不放大——这样一组封面排在一起，字号是齐的。

**居中是写死的**：按整块文字的墨迹包围盒算中心，左右对 `W/2`、上下对 `H/2`。没有 zone、没有绝对 y，唯一例外是 `--offset-y` 的 ±40px 微调。

## 为什么用 PIL 而不是 AI 生图

底图是真人时，图生图会重绘人物：磨皮、改五官、衣物细节变动，做 IP 素材是硬伤。中文标题交给 AI 也必然错字、描边必不匀。

所以**底图不需要改造时一律走代码合成**：底图 100% 保真、文字像素级精准、无水印、零 credits、秒出。只有需要换背景/造场景时才动 AI。
