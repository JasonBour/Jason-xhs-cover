# cover-style-lab · 封面风格库

把「我看到一张好封面，但说不清它好在哪」变成「一组能抄下来的参数 + 一条命令出图」。

风格不是玄学，是参数。能抄下来的才是风格，抄不下来的只是感觉。

---

## 四种风格，一眼选

![四种风格总览](assets/showcase/all-styles.jpg)

同一张底图、同一句话，只换文字样式——差别全在文字上。

| 编号 | 样式 | 识别特征 | 适合 |
|---|---|---|---|
| **01** | [描边压脸](style-library/01-描边压脸.md) | 纯黑描边 + 黄色钩子行 + 白色结论行，多行堆叠、**整块钉在画面正中并撑满 80% 宽** | 一句话标题、真人口播、赚钱认知、工具教学 |
| **02** | [上下压边](style-library/02-上下压边.md) | **顶部一行大标签 + 底部两行大字**，上下一夹、中间整块露人；无描边，顶宋体底黑体 | 真人人设/创始人介绍、双层信息、脸必须露全 |
| **03** | [白条压字](style-library/03-白条压字.md) | **纯白硬边横条** + **黑色宋体**，左对齐，横切人物腰腹 | 提问句、金句、认知/观点类内容 |
| **04** | [彩字压顶](style-library/04-彩字压顶.md) | **顶部超大彩字标题 + 底部两行白字 + 下半身暗化底带**，中间露人 | 强概念短标签、亮底/杂底图、投放素材 |

四张卡内核各不相同，参数不能混用。编号只增不改。

**一句话选法**：要冲击力、脸可以挡 → 01；脸必须露全、还要说清身份和利益 → 02；要可信度、像杂志 → 03；概念词要砸眼睛、底图还偏亮 → 04。

## 画布统一 3:4

**所有风格、所有出图器，只出 3:4（1080×1440）。** 这条不接受参数覆盖，`--width` 只改宽度，高度自动按 3:4 算。

理由很实在：同一批封面要放在一起做合集、做主页九宫格，比例不一致就废了。

## 快速开始

```bash
pip install pillow opencv-python-headless jieba

# 样式01：描边压脸
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --split "如何用 AI|找到属于自己的|隐藏天赋！"

# 样式02：上下压边
python tools/style02_edge_anchor.py \
    --base 底图.png --out 封面.png \
    --split "写给普通人|如何让别人觉得|你的前途一片光明"

# 样式03：白条压字
python tools/style03_white_bar.py \
    --base 底图.png --out 封面.png \
    --split "如何让别人觉得|你的前途一片光明？"

# 样式04：彩字压顶
python tools/style04_title_band.py \
    --base 底图.png --out 封面.png \
    --split "隐藏天赋|如何用AI找到|属于自己的天赋"
```

四个出图器都不重绘底图，只往上面压字，秒出、零 credits、无水印。

## 设计常量（样式01）

全部相对画布宽度 W，换尺寸也成立：

```
字块宽度      0.80 W                 # 硬约束：最宽一行的墨迹宽度，与文案长短无关
安全线        0.88 W                 # 描边外沿绝不越过
描边粗细      0.080 × 本行字号
行距          1.36 × 正文字号        # 行中心 → 行中心
行字号阶梯    0.91 / 1.00 / 1.065    # 首行收、末行放大落点
字块中心      0.5 W, 0.5 H           # 硬约束：整块墨迹钉在画布正中
投影          黑 58/255，偏移 0.0074 W，模糊 0.0056 W
```

**字号不固定，宽度固定**：字号由「让最宽一行刚好 0.80 W」反解出来，实绘后再按真实墨迹宽度回修一次。文案长短只影响字号，不影响字块大小。

两条写死的硬约束，改文案也不许破：

1. **居中**：按整块文字的墨迹包围盒算中心，左右对 `W/2`、上下对 `H/2`。没有 zone、没有绝对 y，唯一例外是 `--offset-y` 的 ±40px 微调。
2. **宽度**：字块最宽一行必须撑到 `0.80 W`。字太小就加行，字太大就压到上限——不允许出现「文案短所以字块缩成一小团」。

## 设计常量（样式02）

```
顶行宽度      0.875 W                # 硬约束：顶行墨迹宽，与字数无关
底行宽度      0.905 W                # 硬约束：底行【末行】墨迹宽（落点，最大）
底行引导宽    0.690 W                # 硬约束：底行【前几行】墨迹宽（引导，小一档）
顶行顶边距    0.056 H                 # 留呼吸，不贴边
底行底边距    0.045 H                 # 留呼吸，不贴边
底行行间空隙  0.034 H                # 上一行墨迹底 → 下一行墨迹顶
暗晕          模糊 0.0038 W，黑 150/255，无偏移
实影          偏移 0.006 H，模糊 0.0032 W，黑 215/255
遮罩          auto：按上下带亮度算 0-120
```

**每行独立反解字号**：底行 4 个字那行一定比 7 个字那行大，这是对的——宽度齐了，大小才有节奏。底行自下而上排，先钉末行底边再往上叠。

**底部两行必须一大一小**：末行撑满 90.5% W，它上面那行只撑 69% W。两行等大是最常见的失误，看着像把标题硬折成两截。

**阴影是两层**：贴轮廓的暗晕负责把字从任何底色上托出来，向下实影负责厚度。只做一层都不够——只有实影，浅底上字会飘；只有大半径光晕，宋体的笔画缝会被灰雾糊死。要让阴影"明显"，该加的是实影的偏移与浓度，不是把光晕摊大。

## 设计常量（样式03）

```
字号          0.0901 W
内边距        0.16 S                 # 白条四边到字身框，四边相等
白条高度      1.32 S
条间距        0.63 S
左边距        0.062 W
白条宽度      本行字身框宽 + 2×内边距   # 随文字伸缩，不固定
白条顶边      0.495 H
```

白条是纯白实色、直角、无投影无描边，边缘 1px 硬切——量过参考图的像素梯度，没有过渡。

## 设计常量（样式04）

```
标题宽度      0.860 W              # 硬约束：斜切后的实际墨迹宽
标题顶边距    0.050 H
标题斜切      默认关                # --italic 18~22 才开，>24° 中文会失真
标题阴影      偏移 0.0022W / 0.0088H，模糊 0.0039 W，黑 175/255（只有一层，不加暗晕）
底行宽度      0.905 W              # 末行（落点）
底行引导宽    0.800 W              # 前几行
底行底边距    0.045 H
底行行隙      0.018 H
底行左对齐    0.038 W
底带颜色      #0E2352 深蓝黑       # 不要纯黑，会把肤色压脏
底带峰值      205/255
底带起点      0.55 H                # 这条线以上 alpha=0，一点不压
底行字号上限  0.85 × 标题字号        # 短句不许比标题还大
```

**斜切是这张卡的身份证**：正着放就退化成样式02。斜切后墨迹宽度没有解析式，必须实绘回修。

**底带不是色块**：0.55 H 以上一点不压，以下按 `t^0.80` 逐渐加深，是缓坡。做成硬边就是样式03 的白条换了个颜色；起点抬到 0.46 H 会让白底图整张蒙灰。

## 为什么用 PIL 而不是 AI 生图

底图是真人时，图生图会重绘人物：磨皮、改五官、衣物细节变动，做 IP 素材是硬伤。中文标题交给 AI 也必然错字、描边必不匀。

所以**底图不需要改造时一律走代码合成**：底图 100% 保真、文字像素级精准、无水印、零 credits、秒出。只有需要换背景/造场景时才动 AI。
