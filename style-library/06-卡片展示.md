# 样式 06 · 卡片展示 / Card Showcase

> **核心画像**：一块**米白圆角卡片**铺满画布，左上三行左对齐大标题（末行用一个强调色），中间一块**深色内容区**（列表 / 截图 / 面板），右下角可叠一个**圆形真人头像**。
>
> 关键识别特征是三条：**米白卡片纸面**（不是照片、不是纯白）+ **三行左对齐大标题、末行换色** + **中间一块深色内容区**。
>
> 和 01-05 的根本区别：**01-05 是文字压在照片上，06 是文字压在纸上、纸再压在画布上**。多了这层纸，标题可以做到最大，底图再脏也不影响可读性。
>
> 气质：产品说明书 / 系统截图 / 工具箱面板。冷静、可信、信息密度高，适合「清单、教程、系统、合集」这类内容——不适合讲情绪、讲故事的选题。

```yaml
id: "06"
name: 卡片展示
status: active
category: 拟物卡片 + 内容面板（工具清单 / 教程 / 系统介绍）

  - 工具清单、App 合集、软件推荐（"我常用的 6 个 AI 工具"）
  - 教程、方法论、系统搭建（"整套工作流长这样"）
  - 需要显得"有东西、有条理"而不是"有情绪"

not_fits:
```

## 一句话记住它

**米白卡片当纸，三行标题当题，深色面板当证据，头像当"我真的在用"。**

---

## 中间内容区放什么

这是这张卡的变量，也是它能不能立住的关键。按信息量从弱到强：

| 放什么 | 怎么喂 | 观感 |
|---|---|---|
| **工具列表**（默认） | `--tiles "名字:色值:用途"` 6 个 | 像 App 的"我的工具箱"设置页，清楚、可信 |
| 真实界面截图 | 直接当底图画进 panel 区 | 最强，有"我真的在用"的实感（参考图就是这条路） |
| 流程图 / 架构图 | 同上 | 适合"系统""工作流"类主题 |

列表模式下每格是「圆角色块图标（白首字）+ 名称 + 用途」，两列三行。名字控制在 10 字符内，用途 5 字内，超了会挤。

## 出图

```bash
# 工具清单（默认形态）
python tools/style06_card_showcase.py \
    --out 封面.jpg \
    --l1 "个人常用的" --l2 "6 个" --l3 "AI 工具" \
    --tiles "ChatGPT:#10A37F:写文案|Claude:#D97757:长文分析|Midjourney:#7C5CFF:出图|Cursor:#5B8DEF:写代码|Gemini:#4285F4:查资料|剪映:#00C8FF:剪辑"

# 加真人头像（强烈建议）
... --avatar 头像.png

# 换强调色
... --accent "#2B6BE0"
```

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--l1` `--l2` `--l3` | — | 三行标题，`--l3` 用强调色 |
| `--tiles` | — | `名字:色值:用途`，用 `\|` 分隔，最多 6 个 |
| `--accent` | `#E8622A` | 末行强调色 |
| `--avatar` | — | 右下角圆形头像图（可选） |
| `--width` | `1080` | 画布宽，高度按 3:4 |

## 已知坑

- **标题第一行字号必须比后两行小一档**（0.104 vs 0.108）。三行等大时，第一行最容易贴到卡片顶边——汉字墨迹比字号框高，按字号算出来的基线会顶出去。
- **内容区的圆角会吃掉小节标题**。`我的工具箱` 这类 header 基线至少要压到 `top + 0.05 W` 以下，否则字顶被圆角弧线切掉一截。
- **纯色圆角方块当图标会显得像待办清单**。必须配名称 + 一句用途，每一格才立得住；只有色块 + 名称时整张图会像 PPT 目录页。
- **没有品牌色时不要乱填色**。工具色最好用官方色（ChatGPT #10A37F、Claude #D97757、Midjourney #7C5CFF、Gemini #4285F4），乱填的紫红蓝会让读者觉得"这不专业"。
- **头像是最容易被省略、也最不该省略的一环**。参考图 90% 的信任感来自右下那张脸；没有头像时这张卡只是"一张好看的信息图"。
