# 样式 03 · 白条压字 / White Bar

> **核心画像**：真人实拍底图 + **纯白硬边横条** + **黑色宋体**，多行左对齐堆叠，白条随文字长度伸缩，横切在人物身上。
>
> 关键识别特征只有三个：**纯白实色条**（不是半透明、不是描边、不是色块蒙层）+ **宋体**（不是黑体）+ **左对齐**（不是居中）。
>
> 和 01 / 02 的根本区别：01 是描边字压脸、02 是裸字压图，**只有 03 给文字加了底**——白条是这套风格的承重墙，去掉就不是它了。
>
> 气质上它是三张里最"书面"的：像从书页上裁下来一条贴上去，冷静、有距离感，适合观点型、认知型、金句型标题。

```yaml
id: "03"
name: 白条压字
status: active
category: 实拍 + 白底条 + 宋体（观点 / 认知 / 金句型封面）
tool: tools/style03_white_bar.py

fits:
  - 观点、认知、金句型标题（"如何让别人觉得…"这种提问句最搭）
  - 想显得克制、有文化感、不像营销号的场景
  - 女性成长、职场、人际关系、心理学话题
  - 底图人物脸部占比大、不想被描边字糊住的场景

# —— 不可变内核 ——
core:
  base_image: 真人实拍底图，人物居中或偏中，背景越干净越好
  overlay: 纯白 #FFFFFF 实色横条 —— 无圆角、无投影、无描边、无渐变、无半透明
  font_class: 宋体（衬线）—— 禁止换黑体，换了就是另一张卡
  align: 左对齐 —— 所有白条左边缘对齐，不是整体居中
  bar_width: 随文字长度伸缩（= 本行字身框宽 + 2×内边距），不是固定宽度
  max_lines: 2-3（2 行是标准形态，3 行及以上白条会盖掉半个人）

# —— 版式参数（全部相对画布宽 W / 字号 S）——
layout:
  canvas: 3:4（1080x1440）—— 全库统一，见 SKILL.md
  size: 0.0901 W                # 字号，S
  padding: 0.16 S               # 白条四边到字身框，四边完全相等
  bar_height: 1.32 S            # = S + 2×padding
  bar_gap: 0.63 S               # 上条底 → 下条顶
  left: 0.062 W                 # 白条左边缘距画布左边
  top: 0.495 H                  # 第一行白条顶边（偏下，横切人物腰腹一线）
  offset_y: 0                   # 整块上下微调，建议 ±60 以内

typography:
  family: 思源宋体（NotoSerifSC-VF）/ 华文宋体 / 宋体
  weight: 600                   # 500 偏细、700 偏闷，600 最接近参考原图
  tracking: 0                   # 字距为零，宋体本身字面就留了气
  color: "#000000"              # 纯黑，不用深灰

bar:
  color: "#FFFFFF"
  radius: 0                     # 直角，不是圆角
  shadow: none                  # 无投影
  stroke: none                  # 无描边
```

## 一句话记住它

**白条做底，宋体做字，左对齐横切一刀。**

---

## 和 01 / 02 的区别（三张放在一起最容易混）

| | 01 描边压脸 | 02 实拍压字 | 03 白条压字 |
|---|---|---|---|
| 文字底色 | 无 | 无 | **纯白实色条** |
| 字体 | 黑体（思源 Heavy） | 黑体 | **宋体** |
| 描边 | 纯黑粗描边 | 无 | 无（靠白条分离） |
| 对齐 | 居中 | 居中 | **左对齐** |
| 位置 | 画布正中 | 顶部，避开脸 | 偏下，横切腰腹 |
| 气质 | 综艺、抓眼 | 高级、图文一体 | 书面、冷静、有距离 |
| 什么时候用 | 要冲击力 | 要呼吸感 | 要可信度 |

## 出图

```bash
# 标准两行（推荐）
python tools/style03_white_bar.py \
    --base 底图.png --out 封面.png \
    --split "如何让别人觉得|你的前途一片光明？"

# 整句自动断成两行
python tools/style03_white_bar.py \
    --base 底图.png --out 封面.png \
    --title "如何让别人觉得你的前途一片光明？"

# 换字重 / 换宋体 / 整块上下挪
... --weight 500 --font stsong --offset-y -40
```

脚本会自动处理：裁 3:4 → 按字宽算白条长度 → 左对齐堆叠 → 墨迹垂直居中 → 输出。运行完会打印每行白条的左右边界、宽度占比和整块底边 y，方便复核。

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--split` | — | 手动分行，`\|` 分隔（推荐，断行位置是设计的一部分） |
| `--title` | — | 整句标题，自动断成两行 |
| `--weight` | `600` | 思源宋体字重，400-900 |
| `--font` | `notoserif` | `notoserif` 思源宋体 / `sourcehan` 思源宋体 Heavy / `stsong` 华文宋体 / `simsun` 宋体 |
| `--offset-y` | `0` | 整块上下微调像素（正=下移） |
| `--width` | `1080` | 画布宽，高度自动按 3:4 算 |
| `--demo-grid` | off | 叠一层 1/10 网格，核验位置用 |

## 字体档

| `--font` | 字体 | 气质 | 什么时候用 |
|---|---|---|---|
| `notoserif`（默认） | 思源宋体 VF | 现代宋体，笔画干净，字重可调 | 绝大多数情况 |
| `sourcehan` | 思源宋体 Heavy | 更重、更厚 | 背景杂乱、需要压住画面 |
| `stsong` | 华文宋体 | 传统、偏细、书卷气 | 文化/教育类内容 |
| `simsun` | 宋体 | 最老派，屏显笔画细 | 复古、报纸感 |

四档只换 `font`，其余参数不动 —— 换字体不换版式，这是本卡的硬规矩。

## 已知坑

- **垂直居中要按墨迹算，不能按字身框**。用 `ascent/descent` 居中，整行字会整体偏上 10px 左右（汉字墨迹在字身框内偏上）。出图器已用满框汉字「国」的墨迹中心作基准修正。
- **白条宽度按字身框算，不按墨迹**。否则带全角标点的行（"…光明？"）白条会在右侧缩进去一块，看着像没做完。
- **`top: 0.495 H` 只适合脸偏上的构图**。人物脸占满画面上半时，白条会压到鼻子，得用 `--offset-y` 往下挪 40-80px。别改成自动居中——这套风格的魂是"横切一刀"，不是居中。
- **字号固定 0.0901 W，不像样式 01 那样反解宽度**。因为白条本来就随字长伸缩，宽度不一致才是它该有的样子。但这也意味着**字数太少时字会显得小**：4 字以下建议凑到 6 字以上，或者接受白条很短这个形态。
- **宋体换黑体 = 换风格**。别觉得"字重不够就换思源黑体"，那是 01 的做法。

| 条间距 | 46px | 0.63 S |
| 白条左边距 | 49-56px | 0.062 W |
| 第一行白条顶 | 713px | 0.495 H |
| 白条边缘过渡 | 1px | 硬边，无羽化 |

参考图里两行白条的左边缘差了 7px（49 vs 56），是原作者的排版误差，本卡统一对齐到同一左边距，不复制这个瑕疵。
