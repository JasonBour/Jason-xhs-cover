# 样式 01 · 描边压脸 / Stroke Stack

> **核心画像**：真人实拍底图 + **纯黑描边**大字 + **强调色钩子行 / 白结论行**双层撞色 + 多行堆叠**直接压住人物脸部**居中。
>
> 关键识别特征只有两个：**黑描边**（不是白描边、不是投影）+ **压脸**（不是避脸、不是贴顶）。这一对组合就是"综艺标题字 / 短视频封面"那股味的来源。
>
> 和「实拍压字」的根本区别：实拍压字无描边、双色是金黄+白、文字**避开**脸、堆在顶部；本卡有描边、文字**盖住**脸、堆在画面中部。两张卡不能混用参数。

```yaml
id: "01"
name: 描边压脸
status: active
category: 实拍 + 描边大字压脸（真人 IP / 短视频封面主打）
tool: tools/style01_stroke_stack.py

fits:
  - 真人出镜的口播/教程/观点封面
  - 一句完整的"钩子 + 结论"式标题（不是短语，是句子）
  - 女性成长、赚钱认知、工具教学
  - 需要在小图缩略状态下仍然一眼读清的场景

# —— 不可变内核 ——

  base_image: 真人实拍底图，人物居中或偏中，头部完整
  overlay: 无蒙层 —— 禁止任何半透明色块/渐变遮罩
  stroke: 纯黑 #000000 描边（不是白描边、不是投影代替）
  color_system: 双层撞色 —— 首行强调色 + 其余纯白，最多两色

colors:
  accent: "#FFD400"     # 首行钩子色，亮黄（可换 #FF3B30 红 / #00E5A0 绿）
```

## 一句话记住它

**黑边框住字，黄字抓眼，白字给答案，整块压在脸上。**

---

## 字体档（同一个样式，三种气质）

| `--font` | 字体 | 气质 | 什么时候用 |
|---|---|---|---|
| `noto`（默认） | 思源黑体 Heavy | 最重、最方正、综艺感最强 | 标题要"砸"下来，画面本身清淡 |
| `yahei` | 微软雅黑 Bold | 略圆、现代、更年轻 | 女性成长/生活类，不想太凶 |
| `heiti` | 黑体 | 硬朗、老派综艺 | 反差感、糙一点更有味 |

三档只换 `family`，其余参数不动 —— 换字体不换版式，这是本卡的硬规矩。

## 出图（PIL 路线，默认且推荐）

本卡**只走 PIL 代码合成**，不走 AI 图生图。原因：AI 会重绘真人（磨皮、改五官），而描边字一旦让 AI 生成，中文必错字、描边必不匀。

```bash
# 最省事：整句标题，自动断行 + 自动定字号
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --title "如何用 AI 找到属于自己的隐藏天赋！"

# 最可控：手动指定分行（推荐，断行位置本身就是设计）
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --split "如何用 AI|找到属于自己的|隐藏天赋！"

# 换气质 / 换强调色 / 换字块位置 / 换画布
... --font heiti --accent "#FF3B30" --zone upper --width 1242 --height 1656
```

脚本会自动处理：裁 3:4 → 断行（jieba 分词 + 禁则）→ 算字号（长文案缩小、短文案不放大）→ 墨迹居中 → 描边 → 投影 → 输出。运行完会打印每行字号和字块中心 y，方便复核。

### 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--title` | — | 整句标题，自动断行 |
| `--split` | — | 手动分行，`|` 分隔（优先级高于 title） |
| `--accent` | `#FFD400` | 首行钩子色 |
| `--font` | `noto` | `noto` / `yahei` / `heiti` |
| `--zone` | `face` | `top` `upper` `face` `lower` `bottom` |
| `--y` | — | 直接指定字块中心 y（精细微调用） |
| `--size-ratio` | `0.116` | 正文字号/画布宽 |
| `--stroke-ratio` | `0.080` | 描边/字号 |
| `--tracking` | `-5` | 字距（按 1080 基准自动缩放） |

## Compose 流程（覆盖 SKILL.md 的 Stage 3 判断）

1. **检查底图**：有没有原视频字幕/水印？有就先修掉（`cv2.inpaint` 局部修复），别让字幕和标题打架。
2. **定断行**：读一遍标题，自己判语义边界，用 `--split` 写死三行。**不要全交给自动断行**——它是兜底，不是标准。
   - 首行放钩子（含英文词/数字最佳，会自动上黄色）
   - 末行放最狠的落点
3. **定字块位置**：人物脸大且居中 → `face`；人物偏上/露肩多 → `lower`；脸被手挡 → `upper`。有偏差用 `--y` 微调 20-40px。
4. **出图后逐字核对**（描边可能糊住小字，缩到 30% 看一眼还认不认得出）。
5. **落盘**：`output/<YYYY-MM-DD>/<标题>.png`，并把可复用底图另存一份。

## 已知边界

- `face` 区固定 0.56H 是经验值。底图主体比例差异大时（4:3 裁 3:4 会放大人物），需要 `--y` 手动微调。
- 单行标题会自动全部上强调色（因为首行规则优先），视觉上比三行版弱一档，长标题尽量不要压成一行。
- 中文断行依赖 jieba；环境缺 jieba 时退回逐字 + 禁则，仍可能把词拆开 —— 所以 `--split` 永远是更稳的路。
- 描边超过 `0.09` 会把细笔画糊成一团（"口"字类会闭合），别贪粗。
- 强调色换成深色（如深红 #8B0000）时，黑描边会失效，必须先换描边色或加白描边兜底。
