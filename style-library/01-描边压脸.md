# 样式 01 · 描边压脸 / Stroke Stack

> **核心画像**：真人实拍底图 + **纯黑描边**大字 + **强调色钩子行 / 白结论行**双层撞色 + 多行堆叠，**整块文字钉在画布正中（左右上下都居中）**，自然压住人物脸部。
>
> 关键识别特征只有两个：**黑描边**（不是白描边、不是投影）+ **绝对居中**（整块墨迹钉死在画布正中，不是贴顶、不是靠下、不是避脸）。这一对组合就是"综艺标题字 / 短视频封面"那股味的来源。
>
> **居中不是可选项，是硬约束**：出图器用整块文字的墨迹包围盒算中心，左右对 W/2、上下对 H/2。不提供 zone、不提供绝对 y，唯一的例外是 `--offset-y` 的 ±40px 微调。
>
> 和「实拍压字」的根本区别：实拍压字无描边、双色是金黄+白、文字**避开**脸、堆在顶部；本卡有描边、文字**盖住**脸、堆在画面中部。两张卡不能混用参数。

  block_center: [0.5 W, 0.5 H]  # 硬约束：整块墨迹中心 = 画布中心
  offset_y: 0                  # 唯一可调项，±40px 以内微调，默认 0

## 一句话记住它

**黑边框住字，黄字抓眼，白字给答案，整块钉在画面正中、撑到八成宽。**

两条写死的规矩，改文案也不许破：
1. **整块墨迹中心 = 画布中心**（左右 + 上下）
2. **字块最宽行 = 0.80 W**（跟参考图一致），文案长短只影响字号，不影响宽度

---

## 字体档（同一个样式，三种气质）

| `--font` | 字体 | 气质 | 什么时候用 |
|---|---|---|---|
| `noto`（默认） | 思源黑体 Heavy | 最重、最方正、综艺感最强 | 标题要"砸"下来，画面本身清淡 |
| `yahei` | 微软雅黑 Bold | 略圆、现代、更年轻 | 女性成长/生活类，不想太凶 |
| `heiti` | 黑体 | 硬朗、老派综艺 | 反差感、糙一点更有味 |

三档只换 `family`，其余参数不动 —— 换字体不换版式，这是本卡的硬规矩。

## 出图（PIL 路线，默认且推荐）

本卡**只走 PIL 代码合成**，不走 AI 图生图。原因：AI 会重绘真人（磨皮、改五官），而描边字一旦让 AI 生成，中文必错字、描边必不匀。

```bash
# 最省事：整句标题，自动断行 + 自动定字号
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --title "如何用 AI 找到属于自己的隐藏天赋！"

# 最可控：手动指定分行（推荐，断行位置本身就是设计）
python tools/style01_stroke_stack.py \
    --base 底图.png --out 封面.png \
    --split "如何用 AI|找到属于自己的|隐藏天赋！"

# 换气质 / 换强调色 / 换画布 / 微调上下
... --font heiti --accent "#FF3B30" --width 1242 --height 1656 --offset-y -30
```

脚本会自动处理：裁 3:4 → 断行（jieba 分词 + 禁则）→ **反解字号让字块撑满 0.80 W** → 墨迹居中 → 描边 → 投影 → 输出。运行完会打印每行字号、字块尺寸和实际宽度占比，方便复核。

**字号不是拍出来的，是解出来的**：先算「让最宽一行刚好 0.80 W」需要多大字号，实绘后再按真实墨迹宽度回修一次（估算与绘图有 1-2% 偏差）。所以同一句文案不管自动断行还是手动断行，出来的字块一样大。

### 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--title` | — | 整句标题，自动断行 |
| `--split` | — | 手动分行，`|` 分隔（优先级高于 title） |
| `--accent` | `#FFD400` | 首行钩子色 |
| `--font` | `noto` | `noto` / `yahei` / `heiti` |
| `--offset-y` | `0` | 在正中基础上的微调像素（正=下移），建议 ±40 以内 |
| `--stroke-ratio` | `0.080` | 描边/字号 |
| `--tracking` | `-5` | 字距（按 1080 基准自动缩放） |

## Compose 流程（覆盖 SKILL.md 的 Stage 3 判断）

1. **检查底图**：有没有原视频字幕/水印？有就先修掉（`cv2.inpaint` 局部修复），别让字幕和标题打架。
2. **定断行**：读一遍标题，自己判语义边界，用 `--split` 写死三行。**不要全交给自动断行**——它是兜底，不是标准。
   - 首行放钩子（含英文词/数字最佳，会自动上黄色）
   - 末行放最狠的落点
3. **位置不用想**：整块文字默认就钉在画布正中（左右上下都居中），这是写死的。只有当人脸明显偏离画面中心、文字压上去很别扭时，才用 `--offset-y ±40` 微调，别养成每次都调的习惯。
4. **出图后逐字核对**（描边可能糊住小字，缩到 30% 看一眼还认不认得出）。
5. **落盘**：`output/<YYYY-MM-DD>/<标题>.png`，并把可复用底图另存一份。

## 已知边界

- 居中是写死的（墨迹包围盒对画布中心）。底图人物明显偏离中心时，文字虽然居中但视觉重心会偏，只能靠 `--offset-y` 微调，调幅别超过 40px，否则破坏标准。
- 三行文字块在 1080×1440 上约占 470px 高（33%），压脸是必然结果——这本来就是这套风格的样子，不要试图让它"避开脸"。
- 单行标题会自动全部上强调色（因为首行规则优先），视觉上比三行版弱一档，长标题尽量不要压成一行。
- 中文断行依赖 jieba；环境缺 jieba 时退回逐字 + 禁则，仍可能把词拆开 —— 所以 `--split` 永远是更稳的路。
- 描边超过 `0.09` 会把细笔画糊成一团（"口"字类会闭合），别贪粗。
- 强调色换成深色（如深红 #8B0000）时，黑描边会失效，必须先换描边色或加白描边兜底。
