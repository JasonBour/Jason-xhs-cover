# 风格卡：上下压边

> **核心画像**：真人实拍底图 + **顶部一行大标签 / 底部两行大字**，上下一夹，**中间整块留给人脸和身体**。字是裸字——没有描边、没有色块，靠极淡的投影和上下渐变遮罩保证可读。
>
> 和样式01 正好是镜像关系：01 把字堆在画面正中压住脸，02 把字推到画面两条边上，中间一点不碰。

```yaml
name: 上下压边
status: active
category: 真人实拍 + 顶部标签 + 底部大字（人物完整露出）

fits:
  - 人物出镜、脸必须完整露出的内容（人设 / 创始人 / 观点输出）
  - 需要一眼说出"身份 + 利益点"的封面
  - 上下都有信息层级：上面是标签（我是谁 / 写给谁），下面是结论（能得到什么）
  - 合集封面、九宫格封面（上下一夹，缩略图里辨识度最高）

# —— 不可变内核 ——
core:
  layout: 顶行 1 行 + 底部 2 行，共 3 行（底行可 2-3 行，顶行只能 1 行）
  anchor: 文字贴上下边，中间不压脸 —— 这是和 01 的分界线
  no_stroke: 无描边、无色块、无底条，纯裸字
  fill: 每行独立撑满目标宽度，字号由字数反解（不设固定字号）
  face_safe: 顶部一行可以碰到头顶，但绝不下探到眼睛以下
```

## 三条识别特征

1. **上下一夹**：顶部一行贴顶，底部两行贴底，中间是完整的人。缩略图缩小到 1/8 也还是这个结构。
2. **每行都撑满宽度**：顶行 87.5% W、底行 90.5% W。所以底行 4 个字的那行，字号一定比 7 个字那行大——这是对的，不要修。
3. **字体分工**：顶行宋体（思源宋 900），底行超粗黑体（思源黑 900）。宋体做标签有质感，黑体做卖点有冲击力。全用黑体会丢一半味道。

## 参数（相对画布，换画布也成立）

```
canvas: 3:4（1080 × 1440），全库统一
top_width:  0.875 W      # 顶行墨迹宽度，硬约束
bot_width:  0.905 W      # 底行每行墨迹宽度，硬约束
top_inset:  0.0335 H     # 顶行墨迹顶边 → 画布顶
bot_inset:  0.0106 H     # 末行墨迹底边 → 画布底
line_gap:   0.037 H      # 底行之间：上一行墨迹底 → 下一行墨迹顶
align:      水平居中（按墨迹算，不按字身框）
size_range: 0.055 W ≤ 字号 ≤ 0.300 W
shadow:      黑 130/255，偏移 0.0021 H，模糊 0.0022 W   # 硬投影，不糊
scrim:       auto        # 上下各压一层黑渐变，按底图亮度自动定 0-120
```

## 配色

默认照抄样式01 的撞色系统：**强调色 `#FFD400` 给顶行（钩子），纯白 `#FFFFFF` 给底部（结论）**。

要反过来（顶白底黄）用 `--accent-line bottom`。除此之外不要自己加第三种颜色。

## 用法

```bash
# 手动分行：第一段是顶行，后面都算底行
python tools/style02_edge_anchor.py --base 底图.png --out 封面.png \
  --split "写给普通人|如何让别人觉得|你的前途一片光明"

# 只给顶部标签和底部整句，底部自动断两行
python tools/style02_edge_anchor.py --base 底图.png --out 封面.png \
  --top "写给普通人" --bottom "如何让别人觉得你的前途一片光明"

# 换强调色 / 换字体 / 微调
... --accent "#FF3B30" --bot-font yahei --offset-y -30
```

脚本会自动处理：裁 3:4 → 每行二分反解字号让墨迹撑满目标宽度 → 实绘后按真实宽度回修 → 顶行贴顶、底行自下而上堆叠 → 硬投影 → 自动遮罩 → 输出。跑完会打印每行字号、墨迹尺寸、宽占比和 y 位置。

## 不要做

- **不要给字加描边**。加了就是样式01，两个风格立刻撞车。
- **不要固定字号**。文案 4 个字和 8 个字必须一样宽，字数差多少字号就差多少。
- **不要把底行三行当默认**。三行会把底部吃掉 25% 高度，人物腿部全没了；只在文案确实长的时候用。
- **不要在浅色底图上关遮罩**。白字压在 180 亮度的灰底上，缩略图里会直接消失。
- **不要为了避开头顶把顶行缩到很小**。这条风格的顶行就是要大，人物头顶被字压住是正常的。

## 踩坑记录

- 投影必须**硬**（模糊 ≈ 2px）。用 7px 的软投影，白字边缘会拖出一圈灰雾，缩略图看像脏了。
- 遮罩按底图亮度自动算：`(max(顶部均值, 底部均值) - 120) × 0.85`，上限 120。深色底图算出来是 0，一点不压。
- 底行是**自下而上**排的：先钉末行底边，再往上叠。反过来排会因为末行字号不同导致底边不齐。
