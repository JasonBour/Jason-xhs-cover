# 拍屏素材做底图

用户给一段 `.mov` / 视频让"截一帧做封面"时走这套。拍屏素材（手机拍显示器）几乎都是脏的，下面每一步都是踩出来的。

## 0. 抽帧不靠猜

```python
cap = cv2.VideoCapture(path)
n = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
for i in range(12):                       # 均匀抽 12 帧
    cap.set(cv2.CAP_PROP_POS_FRAMES, int(n * i / 12))
    ok, fr = cap.read()
    # cv2.imwrite 遇中文路径会写出乱码文件名，**必须用 PIL save**
    Image.fromarray(cv2.cvtColor(fr, cv2.COLOR_BGR2RGB)).save(...)
```

先拼一张联系表（6×2 缩略图）看全局，再挑 3-5 帧原尺寸细看。**选帧标准**：构图正 > 画面有冲击力 > 人物表情。斜得最厉害的那帧先淘汰。

## 1. 拍屏画面必然有三层脏，一层都留不得

| 脏东西 | 位置 | 为什么不能留 |
|---|---|---|
| 浏览器/系统 UI | 顶部 15-25% | 标签栏、URL、书签，一眼"偷拍" |
| 显示器边框 | 四周斜边 | 断掉画面，还带墙面色 |
| 桌面杂物 | 底部 | 键盘、桌布、机箱 |

**别指望文字盖住它们**。文字块只占 15-30% 高度，剩下的 UI 全露着，压得再漂亮也是随手截图。

## 2. 先量斜率再旋转

拍屏的屏幕一定是斜的，直接按横平坐标裁一定切不干净。**不要靠肉眼估旋转角**：

```python
# 在旋转前的图上画 50px 红网格 + 坐标数字，让某一次看图报出
# 「屏幕顶边左端 y=480、右端 y=300」
slope = (y_right - y_left) / width      # 这里 = -0.167
angle = degrees(atan(slope))            # -9.46°
```

**PIL 的 `rotate` 正角是逆时针，方向和直觉相反**：这次的 −9.46° 转完反而更斜，+9.46° 又过冲，最后落在 **+5.3°**。所以要**小步试转、每次把顶边放进网格里验一次**，别信算出来的数。

旋转会重采样、边缘进黑角，所以只旋中心区域够用的角度，四周多裁一点。

## 3. 只裁纯画面，不要补边

试过三种失败的补法，都别再试：

| 补法 | 结果 |
|---|---|
| 单行拉伸填充 | 云被拉成一条条竖线 |
| 紧邻区域强模糊填充 | 和下方锐利画面之间一条硬接缝 |
| 局部模糊打补丁（盖 UI） | 留下一个明显灰方块 |

**正解：直接把 UI 全裁掉，哪怕裁完只剩 650px 宽再放大回 1080**。拍屏本来就软，放大 1.6-1.9 倍损失的那点锐度，比任何补丁都好看。

```python
g = rotated.crop((201, 640, 849, 1504))        # 648x864 = 3:4，纯画面
g = g.resize((1080, 1440), Image.LANCZOS)
g = g.filter(ImageFilter.UnsharpMask(radius=2, percent=115, threshold=3))
```

放大后**必须补一次 `UnsharpMask`**，否则整张糊成一团。`percent` 110-120 之间，再高会出现白边。

## 4. 顶部暗化托字

拍屏的游戏/网页画面顶部大多是亮天光，彩字压上去直接消失。加一层垂直渐变暗化（不是全图压暗，只压上部）：

```python
grad = Image.new('L', (1, H), 0)
for y in range(0, 470):                        # 上部 33%
    grad.putpixel((0, y), int(86 * (1 - y/470)**1.3))
img.paste(Image.new('RGB', (W, H), (4, 8, 22)), (0, 0), grad.resize((W, H)))
```

峰值 80-90 足够。**但如果是亮底，优先换样式而不是加深暗化**——黄条压字（05）黑字压柠檬黄，底图再亮都不用调。

## 5. 游戏 HUD 留着

计时器、小地图、准星这些是画面的一部分，删了反而假。**只处理"被裁成半截"的 HUD**——半截字最难看。做法是裁切时把整块 HUD 排除在外，而不是事后抹。

## 一句话流程

抽 12 帧 → 联系表选帧 → 网格量斜率 → 小步试转摆正 → 裁到纯画面 → 放大 + 锐化 → 顶部暗化 → 压字。
