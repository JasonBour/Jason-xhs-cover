# 风格卡 Schema / Style Card Schema

一张**风格卡** = 一组能被生图模型稳定复现的参数，用于把用户的参考封面归纳成可复用模板。

**铁律**：字段里写参数、写色值、写坐标、写比例——**禁止**写"高级感 / 有质感 / 看着舒服"这类形容词。形容词进不了生图 prompt，参数才能。

> 记不住 schema 没关系——记住这句话即可：**能抄下来的才是风格，抄不下来的只是感觉。**
> Collect 阶段填的是草稿卡（可粗），Taxonomy 收敛成正式卡（必须落到能抄的参数）。

---

## 完整字段

```yaml
# —— 身份 ——
name: <风格名，短，如: 大字冲击 / 留白素净 / 手写温度>
status: draft | active          # draft=在 collect-queue 草稿；active=已入 style-library
category: <大类标签，见"分类维度">

# —— 内容类型（这张卡最擅长承载什么）——
fits:                            # 适合的内容方向，如 赚钱认知/女性成长/情感语录/干货清单
  - ...

# —— 版式 Layout ——
layout:
  structure: <构图骨架>          # 上下分栏 / 左右分栏 / 中央聚焦 / 大字铺满 / 图文拼贴
  text_position: <标题文字位置>  # 上1/3 / 居中 / 下1/3 / 左对齐竖排...
  emphasis: <重点字怎么突出>     # 无 / 大字对比 / 高亮色块 / 下划线 / 放大词
  negative_space: <留白程度>     # 大量留白 / 适中 / 几乎铺满
  margin: <边距>                 # 四周留多少，别贴边

# —— 配色 Palette ——
colors:
  primary:   <主色 色值>         # 背景主调
  secondary: <辅色 色值>         # 次级元素
  accent:    <强调色 色值>       # 标题/重点字/按钮
  text:      <正文字色>
  scheme:    <色彩关系>          # 同色系 / 互补撞色 / 黑白灰+一强调 / 暖调 / 冷调

# —— 字体 Typography ——
typeface:
  family: <字体气质>             # 粗黑无衬线 / 细衬线 / 手写感 / 圆体可爱 / 宋体书卷
  weight: <字重>                 # heavy / bold / regular / light
  case: <字型>                   # 全大写 / 标题化 / 中文竖排 / 中英混排
  shadow: <文字阴影>             # 无 / 轻投影 / 重投影 / 描边
  overlay: <文字叠层>            # 无(字直接压图) / 半透明深蒙 / 半透明浅蒙 / 毛玻璃

# —— 元素 Elements ——
elements:
  frame: <边框装饰>              # 无 / 细线框 / 圆角卡 / 双线框
  stickers: <贴纸/标签>          # 无 / 有哪些(但默认不加小型分类标签)
  highlight: <高亮块/标记>       # 无 / 荧光笔 / 色块强调
  photo_style: <底图(如有)处理>  # 真人出镜 / 商品图 / 纯色背景 / 抽象纹理 / 场景照

# —— 叠层遮罩 Overlay（文字底下那层）——
overlay:
  layer: <蒙层类型>              # 无 / 半透明深色 / 半透明浅色 / 渐变遮罩
  opacity: <透明度 0-1>          # 如 0.4
  reason: <为什么这么叠>         # 保证文字可读性 etc.

# —— 一句话特征（INDEX 里展示用）——
one_liner: <给不熟悉的人一句话描述这张卡的视觉风格>

# —— 代表样本 ——
samples:
  - path: <style-library/<风格名>/sample-01.png>   # 供图生图参考的缩略图
    note: <这张最能代表该风格的点>
```

## 出图 Prompt 模板（Compose 用）

把上面的卡「翻译」成 ImageGen 能吃的 prompt，骨架如下（中文示例）：

```
[图生图模式，input=底图]
画面构图：[layout.structure]，标题文字位于[text_position]，
主色[colors.primary]，强调色用[colors.accent]突出重点字。
文字采用[typeface.family]字体，加[typeface.shadow]，底下叠
[overlay.layer]蒙层(透明度[overlay.opacity])保证可读性。
画面上的标题文案是：[用户文案，逐字保留]。
风格要素：[elements 若有则提]。
比例参考：小红书 3:4 竖版，无黑边，文字居中，极简克制，
不加小型分类标签。
```

**Compose 落地 checklist（出图前自查）**：
- [ ] 用户文案标题已**逐字**放进 prompt（没被改写）
- [ ] 风格参数来自所选卡的字段，不是临场瞎编形容词
- [ ] overlay 蒙层透明度、文字阴影已写明（可读性兜底）
- [ ] 已向用户报告 credits（单张约 5-10）
- [ ] 已确认目标平台比例 / 沿用用户习惯（默认小红书 3:4）
- [ ] `input_fidelity` 设置符合意图：复刻=高，改版=中低

## 分类维度（粗分起步，够用再细化）

首版不强求精细，先铺这几类骨架，收图时对号入座：

| 大类 | 视觉特征一句话 | 常见承载内容 |
|---|---|---|
| 大字冲击 | 超大标题铺满/接近铺满，词冲击 | 观点、争议标题、干货结论 |
| 留白素净 | 大量留白，小字点缀，克制 | 高级感、认知金句、极简 |
| 半透明照片叠字 | 真人/场景照+居中叠半透明文字 | 女性成长、人像 IP 封面 |
| 手写温度 | 手写体字、暖色、生活感 | 情感、陪伴、日常 |
| 撞色吸睛 | 高饱和互补色撞色 | 爆款标题、促销、抓眼球 |
| 拼贴杂志 | 多元素拼贴、贴纸边框 | 干货清单、合集、盘点 |
| 深底霓虹 | 深色底+亮色强调/霓虹 | 科技、夜谈、严肃议题 |
| 纯文案排版 | 无照片，纯字体排版当视觉 | 语录、观点、金句 |
| 商务极简 | 克制的品牌风、留白+细线 | 知识付费、课程封面 |

> 这些是**起点骨架**，不是终点。你投的图会不断催生新卡、合并碎卡——`INDEX.md` 是活的。
